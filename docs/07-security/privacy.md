# Privacidade — fundação

Nenhum formulário, cadastro, cookie de marketing, tracker ou armazenamento de dados de comprador. Logs da aplicação não incluem IP, payload ou identificadores pessoais; hospedagem pode gerar logs operacionais segundo configuração do provedor, a revisar antes da publicação.

Não publicar política jurídica genérica como se fosse da empresa. Identidade do controlador, contato, finalidades, bases aplicáveis, retenção e terceiros são pendências para o checkout e para publicação comercial. Sem dados pessoais de teste reais no repositório.
