# Tracking — fundação

Nenhum SDK ou cookie analítico instalado. Não emitir page_view, add_to_cart ou purchase para destinos externos. Testes e acesso de desenvolvimento não devem ser confundidos com compradores.

Antes da ativação comercial: especificar gatilho, propriedades, origem, destino, finalidade, consentimento e deduplicação de cada evento. Purchase dependerá de confirmação backend. Repositório e UI atuais não geram transações.
